# Report Structure Mind Map

The mind map shows how the report moves from a precisely defined forecasting
question to a bounded conclusion. The four decision dimensions sit underneath
the whole structure because no single error score answers the research question.

![EPQ report structure mind map](report-structure-mind-map.svg)

The supporting report is `report/final-report.md`. The diagram is a navigation
aid; it does not replace the evidence, citations or limitations in the report.
